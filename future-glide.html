Future Lab

That page glided.

You tapped a card on the Future Lab and it grew into this page, where the browser supports it.

What just happened

Both pages carry one line of CSS that says "animate between pages", and each has one element with the same name. The browser pairs the two and grows the card into the banner.

Limited supportNot yet in every major browser engine (Baseline: limited, webstatus.dev, 19 November 2026). In the others you saw the page simply load, which is fine. With reduced motion on, nothing glides.

Back to the Future Lab

@view-transition { navigation: auto; }

/* on the card, on the first page */
.card { view-transition-name: glide; }

/* on the banner, on this page */
.banner { view-transition-name: glide; }
